# Feature artwork

These original SVG symbols are covered by the repository MIT license. Each feature has its own domain symbol, accent color and concise description in `presentation.json`. The Go generator keeps names on one line and uses true middle alignment for the icons. The documentation generator shares the compact, subtly tinted icon badge treatment used for driver artwork. Feature names are real text in the README so browser search and text selection work. Edit these sources and regenerate with `make generate`; do not edit the generated badges directly.
